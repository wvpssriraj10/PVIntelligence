About / model information

Architecture

The base forecaster is a stacked LSTM → Dropout → GRU → Dense network that consumes a 24-hour rolling window of irradiance, temperature, cloud cover, and time-of-day features to predict next-hour solar output.

Dataset

Region A: 120 days of hourly generation data. Region B: 18 days — intentionally data-scarce, to demonstrate what transfer learning buys you.

Transfer learning methodology

Region A's early layers are reused as a feature extractor for Region B. Training from scratch, a frozen extractor, and full fine-tuning are compared; fine-tuning needs far less Region B data for comparable accuracy.

Explainability

SHAP attributes each prediction to individual input features by measuring their marginal contribution across feature coalitions, producing an interpretable breakdown of why the model predicted a given output.

Metric definitions

RMSE penalizes large errors more heavily; MAE is the average error magnitude and is less sensitive to outliers.

Privacy & terms

This demo uses only synthetic data. Session analytics are page-view counts stored in your browser only, never transmitted. Forecasts are illustrative and not for operational or financial decisions.
