About / model information

Architecture

The base forecaster is a stacked LSTM → Dropout → GRU → Dense network consuming a 24-hour rolling window of irradiance, temperature, cloud cover, and time-of-day features to predict next-hour solar output.

Dataset

Region A: 120 days of hourly generation data (650 kWp plant). Region B: 18 days — intentionally data-scarce, to demonstrate transfer learning's benefit.

Transfer learning methodology

Region A's early layers are reused as a feature extractor for Region B. Fine-tuning needs 80% less Region B data for comparable accuracy versus training from scratch.

Explainability

SHAP attributes each prediction to individual features by measuring marginal contributions, producing an interpretable breakdown sorted by absolute impact.

Metric definitions

RMSE penalizes large errors more heavily. MAE is average error magnitude. R² measures variance explained — 0.94 means 94% of output variation is captured by the model.

Privacy & terms

This demo uses synthetic/historical data. Session analytics are page-view counts stored in your browser only, never transmitted. Forecasts are illustrative and not for financial decisions.
